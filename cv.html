Selected work

nightshift — detection range with ground truth

Python · github.com/Flaxo49ja/nightshift

Collects journald and auditd telemetry from one host, applies JSON detection rules, injects safe loopback-only techniques with the ground truth written first, then scores recall and precision against it. Reports techniques the collector cannot see as no telemetry, so a blind spot never reads as a miss. 179 tests, no network, no system changes. One run scored 100% recall on 1 of 1 scorable technique at 33% precision; scoping scoring to the injection window took the same events to 100%, with the two out-of-session detections still printed and separately counted.

PhishGuard — phishing detection in the browser

Python, TypeScript · github.com/Flaxo49ja/phishguard

Logistic regression over 18 lexical features of a URL, trained on 107,355 URLs and exported to a 2 KB model that scores inside the page with no network call, so the URL being judged is never uploaded. Per-feature occlusion explanations, ROC-AUC 0.954.

mz-threat-feed — regional threat intelligence

TypeScript, Python · live dashboard · github.com/Flaxo49ja/mz-threat-feed

Daily pipeline that deduplicates IOCs from URLhaus and AbuseIPDB, resolves them against 4,055 prefixes across 16 SADC countries taken from RIPEStat, and triages regional security news. Publishes a static dashboard from GitHub Actions; one run checked 5,400 indicators and found 103 on SADC-registered address space.

ioc-triage — one verdict per indicator

Python · github.com/Flaxo49ja/ioc-triage

Queries five free intelligence sources in parallel and returns one weighted verdict with scriptable exit codes and a 24-hour SQLite cache that stays inside the free tiers.

Research

Automated analysis of HTTP security header implementation across Mozambican and global websites

Research Methodology (RM_2026-ii), Universidade São Tomás de Moçambique · 2026 · github.com/Flaxo49ja/header-study

Sampled 68 Mozambican sites across government, banking, education and commerce plus 40 international sites for comparison, scored six headers correct / weak / missing, and tested category differences with chi-square. Mozambican sites averaged 38.2 against 52.7 internationally; 68.2% were missing two or more headers. 42 of the 68 failed to complete a handshake from my vantage point — reported as a result, not dropped from the sample — which made reachability the finding, not configuration drift.
